## 📱 Description

**BuzzChat** is a real-time messaging application built with Kotlin for Android. It supports 1-on-1 messaging, group chats, and user authentication. Powered by Firebase, it ensures secure, fast, and synchronized communication across devices.

---

## ✨ Features

- 🔒 **User Authentication** — Firebase-based login & registration  
- 💬 **Real-Time Messaging** — Instant delivery using Firebase Realtime Database / Firestore  
- 👥 **Group Chats** — Create and join chat groups with ease  
- 🔐 **Message Encryption** — Messages are securely encrypted before being sent  
- 🖼️ **Media Sharing** — Send images, audio, and more (optional feature)
- 🌙 **Dark Mode Support** (optional)

---

## 🛠️ Tech Stack

- **Language:** Kotlin  
- **Platform:** Android  
- **Backend:** Firebase Authentication, Firebase Firestore / Realtime Database  
- **Architecture:** MVVM (Model-View-ViewModel)  
- **UI:** Jetpack Components, Material Design
